# Diabetes Prediction

A machine-learning project for predicting diabetes risk from patient health attributes.

## Project Overview
This project demonstrates a supervised machine-learning workflow including data preparation, exploratory analysis, model training, comparison, and evaluation using Python.

## Tech Stack
Python · Pandas · NumPy · Scikit-learn · Jupyter · Matplotlib

## Workflow
1. Inspect and prepare the dataset
2. Perform exploratory data analysis
3. Prepare features and target
4. Train classification models
5. Compare model performance
6. Evaluate the selected model
7. Document results

## Repository Contents
- `Model training code.ipynb` — model training and experimentation
- `Diabetic Prediction Code/` — project code
- Supporting project documentation

## Disclaimer
This project is for educational purposes only and is not a medical diagnostic system.
